# Heckle

> **Personalities you own. Takes that live forever.**

Heckle lets you mint an AI fan personality as an **ERC-7857 INFT** on **0G mainnet**, attach it to a
live event, and watch it generate in-character "takes" — each one produced by **TEE-attested 0G
Compute**, stored immutably on **0G Storage**, and committed **on-chain**. Predictions are graded and
**reputation** accrues to the token. Sell the character and its entire take history + reputation travel
with it.

Built for the **Zero Cup** group stage. Live on 0G mainnet (chainId **16661**).

- **Repo:** https://github.com/winsznx/heckle
- **One-liner:** *AI fan personalities you own as INFTs — heckle live events with takes logged to 0G Storage and reputation that travels with the character.*

---

## Why it matters — the four 0G primitives, each load-bearing

Strip any one and Heckle stops being Heckle. That's the Zero Cup "Rule 01" test cleared.

| Primitive | What it does in Heckle | Strip it and… |
|---|---|---|
| **0G Chain** | `HeckleCharacters` / `HeckleEvents` / `HeckleTakes` hold every mint, attachment, take commitment, and reputation update on 0G mainnet. | nothing settles; characters aren't ownable. |
| **0G Compute** | Every take is generated by a TEE-verifiable (`TeeML`) provider; the response signature is recoverable against the provider's on-chain `teeSignerAddress`. | no provable, attested takes. |
| **0G Storage** | Every take blob, every personality blob, and the event metadata live on Storage, retrievable by Merkle root. | takes can't be replayed or audited; history can't travel with the token. |
| **ERC-7857 INFT** | The character *is* the token — owned, transferable, with reputation + take history bound to it. | characters can't be assets. |

## How it works

```
Owner ── mints ──▶ ERC-7857 INFT (personality blob → 0G Storage root = tokenURI)
   │
   └── attaches character to an event (on-chain)
                    │
   Inference agent ─┤ watches HeckleEvents.CharacterAttached
                    │ per beat of the event timeline:
                    │   1. build prompt from archetype + brief + beat
                    │   2. 0G Compute (TEE) → take text + attestation signature
                    │   3. upload take blob → 0G Storage (root)
                    │   4. HeckleTakes.commitTake(characterId, eventId, root, kind)
                    │
   Post-event ──────┘ grade prediction → reputation increments on-chain
```

The public timeline (`/events/[id]`) streams `TakeCommitted` events, fetches each blob from Storage,
and renders it live. A character's profile (`/characters/[tokenId]`) shows its full, retrievable take
history with 0G Storage + chainscan links.

## Quickstart

```bash
git clone --recurse-submodules https://github.com/winsznx/heckle
cd heckle
# already cloned without submodules? fetch the Foundry deps (forge-std, OpenZeppelin):
git submodule update --init --recursive

pnpm install

# contracts
pnpm contracts:test          # 6/6 Foundry tests

# web (connects to the live mainnet contracts by default)
cp apps/web/.env.local.example apps/web/.env.local   # optional; addresses are baked in
pnpm dev                     # http://localhost:3000
```

To run the inference agent or (re)deploy contracts, see **[DEPLOY.md](./DEPLOY.md)** — those steps
need a funded 0G wallet.

## Contracts

```bash
pnpm contracts:build         # forge build (solc 0.8.24, evm cancun)
pnpm contracts:test          # forge test -vv  → 6 passing
```

- **HeckleCharacters** — minimal ERC-7857-compatible INFT (ERC721 + URIStorage + Ownable). `mint`
  stores the personality Merkle root as both `tokenURI` and the on-chain data hash. Standard ERC-721
  transfer works; the full ERC-7857 encrypted-metadata transfer-via-oracle is deferred to R32.
- **HeckleEvents** — event registry: `registerEvent`, `setStatus`, `attachCharacter` (the signal the
  agent watches).
- **HeckleTakes** — `commitTake` (committer-gated) + sqrt-weighted reputation; `gradePrediction`.

Deploy with `forge script script/Deploy.s.sol:Deploy` — full runbook in [DEPLOY.md](./DEPLOY.md).

## Inference agent

The agent ([`apps/inference-agent`](./apps/inference-agent)) turns an attached character into a stream
of attested takes:

1. Watches `HeckleEvents.CharacterAttached` for the demo event.
2. Loads the character's personality blob from 0G Storage (via `tokenURI`).
3. Walks the event timeline; at each beat it builds a prompt from the archetype seed + personality
   brief + beat context.
4. Calls a **TEE-verifiable 0G Compute provider** (`deepseek-chat-v3` by default), recovering the
   response signature for on-chain verification against the provider's `teeSignerAddress`.
5. Uploads the take blob to 0G Storage and commits the root with `HeckleTakes.commitTake`.
6. After the final beat, grades the winner prediction and increments reputation.

```bash
pnpm agent                                                   # live watcher
pnpm --filter @heckle/inference-agent exec tsx src/demo-seed-full.ts --confirm   # one-shot demo seed
```

> The agent reuses an existing 0G Compute ledger if the signer already has one funded, so it does not
> re-fund the minimum on every run.

| Var | Purpose |
|---|---|
| `NEXT_PUBLIC_HECKLE_CHARACTERS` / `_EVENTS` / `_TAKES` | contract overrides (defaults baked in) |

**`apps/inference-agent/.env`**

| Var | Purpose |
|---|---|
| `AGENT_PRIVATE_KEY` | signer: pays storage, commits takes, contracts owner |
| `HECKLE_CHARACTERS` / `_EVENTS` / `_TAKES` | contract addresses |
| `ZG_RPC_URL`, `ZG_STORAGE_INDEXER` | 0G endpoints |
| `ZG_COMPUTE_PROVIDER`, `ZG_COMPUTE_MODEL` | pin a TEE provider (else auto-discover) |

See [`.env.example`](./.env.example) for the full template.

## Design system

Pure black/white, newspaper-on-chain. The whole palette is five tokens (`--ink`, `--paper`, `--rule`,
`--whisper`, `--shadow`) wired into Tailwind 4 via `@theme inline`. **Token-strict**: no hex literals
in components, no arbitrary `text-[Npx]` / `max-w-[Npx]` classes, no italics — everything resolves
through design tokens. Fonts (Fraunces / Inter / JetBrains Mono) are self-hosted in `public/fonts`.
